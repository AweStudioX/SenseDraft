# Local history

History is optional and disabled by default. Enable **Save analysis history** in Settings → History to save successful analyses made after that point. Each captured input has one entry: regeneration updates its suggestion, and a verified replacement marks it as replaced and stores the final edited English. Failed or cancelled analyses are not saved. Turning history off stops new entries but leaves existing entries available until deleted.

History contains the original input, suggested English, Chinese meaning, explanation, ambiguity, provider label, timestamp, and replacement status. It is stored only on this Mac, with no sync or export. Settings → History offers 7 days, 30 days, or No limit; No limit is the default and has no time or count cap. Choosing a shorter period immediately removes older entries. The Review panel near the input has a History button for searching and copying past suggestions without leaving the panel. Settings → History provides full details and management. Search matches the original, English, and Chinese text; the detail view supports copying English, deleting one entry, and clearing all entries from the list. Deletion removes the history file or rewrites it without the deleted entry; it does not promise forensic erasure of filesystem snapshots or backups. With No limit, the encrypted file can grow and loading or saving it can become slower.

The history file is AES-GCM encrypted under the user's Application Support/SenseDraft directory with owner-only file permissions. Its 256-bit key is stored as a generic password in macOS Keychain. If the file cannot be decrypted, the app shows an error and does not overwrite it. Clearing history removes the file and allows new entries to be saved. Existing API credentials and captured text never enter diagnostic logs.
